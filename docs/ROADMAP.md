# Roadmap

1. Preserve and package the working local console; add repeatable regression tests to this repository.
2. Improve task relevance and style evaluation using synthetic fixtures and approved writing samples.
3. Add privacy-preserving operational logging and storage interfaces.
4. Add SQLite with migrations, backup/restore and provenance-aware memory.
5. Add personality IDs and immutable historical snapshots.
6. Add directional relationships and multi-personality sessions, isolating simulated events from real memories.

Each stage needs explicit acceptance tests. Conversational imitation remains an experiment, not a guaranteed reconstruction of a person.
